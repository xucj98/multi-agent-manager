# 任务文档实际操作验收

目标：仅根据 MAM 当前 AGENTS.md、README 和 CLI 帮助完成一次普通执行者交付，验证操作说明是否足够明确。

任务内容：确认 MAM 三个顶层命令的用途，并按文档发布本任务简报。简报说明三组命令的用途、任务要求与 workspace 信息的来源、Manager 和执行者各自编辑什么文件以及如何发布；记录过程中实际遇到的障碍，没有障碍则如实说明。

本任务为只读使用与文档验收，无代码修改，不需要创建 worktree、安装环境、跑单元测试或使用 GPU。无需阅读实现、历史任务或设计文档。使用当前已安装的 mam 和共享管理仓库中的文档即可；按文档规定编辑交付文件，其余内容不修改。不创建额外任务或 subagent。

Manager 将独立检查实际工具调用轨迹，包括定位文件是否清楚、有无重复或与任务无关的查询。交付后保留本任务工作区，由 Manager 验收归档。
