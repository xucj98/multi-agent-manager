## 3. P0：HF 当前能识别协议效果，尚不能识别“多次更新本身”

证据：sections/03_method.tex:72–91、sections/06_real_world.tex:3–43，计划第 66 行。fixed 在一个 K30 动作块中每 5 行查询一次，新状态只在下一次正常动作查询生效。到边界时，它既看过更多中间观察，也拥有最后一次较新的观察和更短预测跨度，还做过更多联合采样及缓存递推。

因此 fixed 对 baseline 的差异可以归因于这组部署变化的整体，不能直接区分：中间多次信息积累是否必要，还是边界前最后一次刷新已经足够。更不能把 J 的 probe 称为对实际执行动作条件化的当前状态滤波器：新联合预测可能对应被丢弃的新动作，旧动作块仍在执行。时间索引对齐是必要条件，不消除这种动作条件差异。

建议增加 **LR（late refresh，边界前刷新）**，不训练新模型：

- 与 fixed 共用 H50/K30、每 5 个已完成 policy rows 的观察与 probe 日程、逐 episode action key0、独立 probe RNG、原来的 decoder 和字段获取/锁存规则。
- 在块起点 a 发出原动作及预测。在 a+5/10/15/20 的 probe 保留同等调用和记录，但输出不进入后续正式缓存；这些查询使用从块起点预测按时刻解码出的参考缓存，而不是前一个 shadow probe 的输出。
- a+25 的 probe 用当时新观察及同样时间对齐的、未递推刷新的缓存；在 a+30 的正常动作查询前，消费该最后一次预测的零基第 4 行，其目标时刻恰为 a+30。fixed 在相同边界也使用距边界 5 行的最后一次预测。保留 acquisition/latch 语义；不存在下一查询的终止片段不伪造刷新收益。
- 同一完整块内保持 probe 次数和最后观察年龄相同，避免把最后一次新观察或减少计算量混进 fixed/LR 的主要差异。轨迹在干预之后可能分叉，不要求不同成功长度的 episode 总调用数相同。

**fixed−LR** 检验的是此实现中中间 probe 对递推缓存路径的附加作用；**LR−baseline** 检验较新的边界前刷新协议。它们仍不单独分离视觉信息、重复采样和递推运算的每个贡献，也不使状态预测成为物理事实。如果 fixed≈LR 且两者优于 baseline，应形成“较新边界状态足够”的结论，不能继续主张密集状态递推必要。若仅估计错误减少而成功率不变，应报告估计收益与控制收益分离。

原有 event−fixed 可以保留为“允许提前重规划的整体效果”。没有周期重规划 / 合适成本比较时，不宣称事件选择策略优于普通更频繁重规划，也不宣称最优触发。无需为当前窄结论自动追加完整 K/row 网格。

## 4. P0：JE 的权重合同必须逐样本写成可验证公式

证据：计划第 56、60 行及 sections/03_method.tex:48–62、sections/04_setup.tex 的有效损失。JE 与 T 共享被消费第 29 行及 t+30 目标，这是一个有解释力的对照；但“固定 H 归约并归一总 phase 权重”还不足以唯一确定实现。

令原 T 的公共有效权重为 `w[b,j] = 1[t+j+1<=L] * 1[t+30<=L]`，`v[b]=sum_j w[b,j]`。保持原有 B×H×D 分母及字段倍率不变，推荐 JE 权重：

`w_JE[b,j] = v[b] * 1[j=29]`。

当剩余 30–49 行时，应使用该样本的 v[b]，不能一律乘 50；剩余不足 30 行时 v[b]=0。只在全 batch 上统一调倍率也可能改变长短尾样本的相对权重。验收应包括剩余 29/30/31/50 行、全无效 batch、实际启用的 loss 分支，以及机器人坐标和其他语义字段完全一致。正文已经说明旧 `key_state_loss_weight` 在某条禁用 token 分支不起作用，不能仅核对配置名就认定倍率生效。

这是**每个样本的 phase 系数总质量相同**，不是实际 loss 值或共享网络梯度范数必然相同。JE 将多个有不同噪声、位置特征和网络依赖的输出约束集中到消费行；优化与梯度分配仍是干预的一部分。因此可说“同一消费目标、相同样本权重预算下的行监督分配效果”，不能说已排除一切优化解释，也不能把它称为纯标签信息量或纯时间效果。先做合同 smoke，不应为了补一个未归一化 JE 而默认再加一套正式模型。

## 5. P1：JC、SF 各自有意义，但不足以拼出无混杂结构因果效应

| 对照 | 可以支持的结论 | 必须保留的边界 |
| --- | --- | --- |
| J / T | 同一消费行参考时刻下，逐帧与重复 endpoint 的目标分配效果 | 非消费行目标、优化及阶段边界混合改变；不是“旧状态 vs 新状态” |
| T / JE | 同一 endpoint、同样本权重预算下，监督行分配效果 | 不保证等梯度、等优化难度；单 train0 结果条件于这两个模型 |
| T / JC | joint 实现中当前目标与 endpoint 目标构造及其后续消费协议差异 | JC 的 t 标签到下一 query 时已旧 30 行，改变了反馈年龄和 reference-input / deployment-cache 错位；若放开尾部有效样本会再加一个混杂 |
| S / SF | serial 当前语义改成未来语义的一组完整改变 | 当前动作训练会条件于未来参考 phase；部署依赖未来预测，动作条件的意义已变 |
| J / U | 同时改变训练教学与部署递推输入的作用 | 不是同 checkpoint 的纯 recurrence 开关 |
| J / C | 某个历史字段输入及其辅助监督的整体语义贡献 | 不是仅改变表示形式或仅检验动作读不读这个字段 |
| N / S / J | 规定预算下完整实现的差异 | 架构、loss、教学、预测/消费时间及解码均可不同 |

SF 还有一个需明确的时间问题：普通 S 在 a 时预测 phase(a)，缓存留到 a+30 时作为 lag30 输入；SF 若在 a 时预测并缓存 phase(a+30)，下次收到的 phase 已对应“当前”，但训练若仍喂 phase(t−30)，phase 输入的年龄错位就从原合同改变了。若为纠正它又改训练输入，则改变项更多。必须逐字段写出训练 previous、target、当前动作条件、部署 next-cache 的四个绝对参考时间，不能只写“当前改未来，属性不变”。

JC/T 和 S/SF 不能成为一个干净的“架构×目标时间”2×2 设计：输入教学、FM/CE、动作条件位置和缓存年龄仍不统一。当前核心故事不需要同时跑完它们；我建议将两任务 JC/SF 四个未开始模型移出必跑矩阵。若以后真的研究这些协议，先冻结上述四个时间合同再另行登记。

C 应保留维度、有效样本和其他字段损失，明确常量值、unknown/acquisition 和 decoder 的处理，避免常量意外触发别的逻辑分支。rearrange 原始空垫侧与 put-back 原始位置这两个 C 足以回答当前的局部内容问题；不需要再围绕按钮增加专用臂。

## 7. P1：现有 HF 幅度与成本不足以支持肯定改善或效率主张

从冻结的 `hf_rearrange_fixed_paired_outcomes_20260914.json` 四格数独立计算：两者成功 231、仅 baseline 成功 23、仅 fixed 成功 37、两者失败 9。净 +14/300 = +4.67 pp，同时存在 23 次由成功变失败。

按 eval seed 分层，在每层 100 个配对差值上重采样 100,000 次，得到约 **[−0.33, +9.67] pp 的 95% percentile 区间**。这是针对冻结配对数值的条件性计算，不是远端原始场景的再次验收。它说明当前证据既未清楚排除零，也不能据此宣布等效；更不能把这一个开发 checkpoint 的 +4.7 pp 作为全论文已证实改善。

冻结计数另有 4,397 次普通 action call、21,171 次 probe，probe / action call 约 4.81。总联合推理调用数相对该 fixed 轨迹自己的普通 action call 约 5.81 倍；这**不是**相对 baseline 的延迟实测倍数。报告实际延迟、每成功任务代价、episode 时长及 probe 开销，才能判断是否值得。小状态维度不等于低总成本。

不建议看到区间跨零就追加批次直到显著。先完成冻结 contrasts、独立任务及诊断，报告区间。若希望主张“没有有意义收益”，须事先定义有实际意义的效应阈值并让区间足够窄；300 集本身不提供等效保证。

## 8. P1：九任务与 V 必须能解释；具名外部系统取决于主张范围

保留全部九任务和固定 J 参照是正确方向。训练前须逐任务锁定字段可观测来源、何时获取、unknown、事件证据和保留规则。特别是 battery 的 phase 不等于完整尝试集合；observe_and_pickup 不得输入尚不可知的匹配答案；ranking 不得把隐藏排序当观测；press_button 需要实际事件与可知目标；swap_T 需要初始位姿与坐标一致。这些属于原 36 个 N/S/J/V 模型的准入合同，不是默认新增实验。若改变了已训练模型合同，不能将不匹配模型静默标为可复用；届时替换数量必须另报。

V 的初始图像锚点加最近四次 query 和当前帧，确实是必要且有用的具名“本地视觉历史基线”。它与显式状态共享 backbone、示范、动作日程时，可以说明**该指定历史窗口实现**与指定语义协议在固定数据预算下的取舍。它不能代表最强视觉记忆方法；相同 backbone / batch / steps 也不意味着视觉 token 数、FLOPs、有效可读历史和额外监督相同。

V 尚未通过 cache/reset 与真实 batch32 显存验收，是主比较的实质依赖。先确认训练历史只来自当前之前、训练与部署的 query 间隔和缓存规则一致、重复帧去重及缺帧 mask、每个 episode reset、保留初始观察、优化实际在学习。先记录 throughput、内存和收敛诊断，再安排九模型。若必须统一修改图像预算，冻结后九任务一致执行，不能逐任务削弱 V。

根据该稿自己在 Related Work 中声明的范围，S 不是 SAGE 复现，V 不是 NativeMEM，引用具名方法也不是匹配比较。对于“固定语义接口的仿真机制实证”，**不把 NativeMEM 复现列为本轮硬门槛**；因此本轮外部方法新增训练 0、评估 0。最终不得声称优于现代记忆方法、SOTA 或最有效记忆架构。若保留这样的竞争主张，必须另做具名外部系统的可核对本地比较并披露其预训练/对齐阶段、额外数据与成本，不能靠九任务 V 替代。

同样，我不把“没有真机”单独视为这篇仿真实证研究的否决条件；但真机部署、物理时钟与真实机器人改善均不能由暂停模拟器推理推出。本轮 wash/drawer 新增训练 0、正式物理评估 0，不把训练示范回放充作物理验证。

## 11. 对最终 RA-L 实证贡献的验收判断

按以上窄主线，具有潜力的成稿应同时交付：可解释且保留失败任务的九任务 N/S/J/V 图景；至少一条由合适对照辨别的发现；一个事先指定的非开发场景验证；与该发现一致的状态/动作诊断和实际成本；与训练重复覆盖相称的结论。已有 50 条训练示范不能兼任未声明的泛化诊断集，新增独立验证示范若用于估计精度须另登记数据用途，但不用因此默认增加在线评估批次。
