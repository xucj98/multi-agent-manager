# 升级到 0.2.2

0.2.2 保持 0.2.1 的实例数据结构不变。本版数据迁移仅更新版本收据，保留任务、job、消息和 service 记录。

按[安装说明](../install.md#更新)先停止各实例 service，再更新程序，逐实例运行 `mam service upgrade`。确认 `mam service status` 中的程序和数据版本均为 `0.2.2`，再启动 service。安装器会保存安装 smoke 和 Codex 兼容性验收证据。

当前程序全部通知使用 `user` 渠道。`service upgrade` 在 `.local/` 备份后把旧 `tool` 设置保存为 `user`，工具渠道设置已停用。新版 daemon 也不会按旧设置生成工具通知；更新后须重启 daemon。已有错误工具结果不会自动从 Codex 线程历史中移除。

任务换人统一由新执行者调用 `mam task start TASK-ID` 接手。`mam service rebind-manager` 用于实例 Manager 接管。

`mam task list` 现在显示标题、任务状态、TASK-ID、执行者、agent 状态五列。依赖原有表格列的项目脚本需要按新列调整；需要任务详情时使用 `mam task status`。

从更早版本升级时，按顺序阅读 [0.2.0](0.2.0.md) 和 [0.2.1](0.2.1.md) 的适配说明。保留的迁移链为 0.1.0 → 0.2.0 → 0.2.1 → 0.2.2。
