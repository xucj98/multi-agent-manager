# 升级到 0.2.1

0.2.1 保持 0.2.0 的实例数据结构不变。`mam service upgrade` 会写入新的
`0.2.1` 数据版本收据，不重写任务、job、消息或 service 文件。

安装程序会运行安装 smoke 和 `mam-codex-check`，并把验收摘要及原始 JSON
保留在 `$HOME/.local/share/multi-agent-manager/install-evidence/`。完整的
0.1.0 -> 0.2.0 -> 0.2.1 升级链由 `scripts/test_integration.py` 验收。

升级后按既有流程逐实例运行 `mam service upgrade`，检查 `mam service status`
中的程序和数据版本均为 `0.2.1`，再启动 service。
