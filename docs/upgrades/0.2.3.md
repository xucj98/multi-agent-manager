# 升级到 0.2.3

0.2.3 保持 0.2.2 的实例数据结构不变。本版数据迁移仅写入新的版本收据，保留任务、job、消息和 service 记录。

按[安装说明](../install.md#更新)先停止各实例 service，再更新程序，逐实例运行 `mam service upgrade`。确认 `mam service status` 中的程序和数据版本均为 `0.2.3`，再启动 service。

通知继续使用 `user` 渠道；`mam task rebind` 已移除，任务接手使用 `mam task start TASK-ID`。

从更早版本升级时，按顺序阅读 [0.2.0](0.2.0.md)、[0.2.1](0.2.1.md) 和 [0.2.2](0.2.2.md) 的适配说明。保留的迁移链为 0.1.0 → 0.2.0 → 0.2.1 → 0.2.2 → 0.2.3。
