# 0.1.0 Program Baseline

`multi_agent_manager/` is the real installed package retained by the MAM
persistence audit, task `2eb71f96-e221-4571-9e18-c3352fc7634f` in the mam-dev
management repository. The files are copied verbatim from its
`files/old_source_snapshot/`; `package_hashes.txt` is copied from the same
archive and is checked before creating any 0.1.0 test instance.

There is no single Git commit matching all files in the old installation.
This test baseline is therefore kept as an immutable source snapshot. It is
the sole 0.1.0 data writer used by the integration harness.
